1. Bots.Business (BJS) Integration

Use this code inside any BJS command to fetch your points.

// Fetch Points via Kumar API
var botId = ""; 
var serverUrl = "https://kumar-lac.vercel.app/api/bot";

HTTP.post({

        "action": "getScore"
    },

});
2. Python (Telebot / Aiogram) Integration

Use the `requests` library to connect your python bot backend.

import requests
import json

KUMAR_API = "https://kumar-lac.vercel.app/api/bot"
USER_ID = ""

def fetch_points():
    headers = {"Content-Type": "application/json"}
    payload = {
        "userId": USER_ID, 
        "action": "getScore"
    }
    
    try:
        res = requests.post(KUMAR_API, headers=headers, data=json.dumps(payload))
        data = res.json()
        if data.get("success"):
            return f"You have {data['score']} points!"
        else:
            return "API Error."
    except Exception as e:
        return str(e)
3. Node.js (Fetch) Integration
const fetchKumarAPI = async () => {

            userId: "",
            action: "getScore"
        })
    });
    
    const data = await response.json();
    console.log("My Points:", data.score);
};
