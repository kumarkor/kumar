Vercel API Documentation

All requests must be sent as JSON. Connect your Telegram Bot (Bots.Business or Python) directly to this endpoint. Your Firebase database credentials are hidden securely on the Vercel server.

POST https://kumar-lac.vercel.app/api/bot

Required Payload Parameters

ParameterTypeDescription
userIdStringYour exact 5-Digit Developer ID ()
actionStringRequired. The task you want the server to perform.

1. Fetch Score Action

Action: getScore

Bots.Business /my_score 
HTTP.post({
    url: "https://kumar-lac.vercel.app/api/bot",
    headers: { "Content-Type": "application/json" },
    body: {
        "userId": "",
        "action": "getScore"
    },
    success: "on_score_reply"
});

2. Fetch Question Action

Action: getQuestion. Retrieves a new math question from server.

Bots.Business /get_question 
HTTP.post({
    url: "https://kumar-lac.vercel.app/api/bot",
    headers: { "Content-Type": "application/json" },
    body: {
        "userId": "",
        "action": "getQuestion"
    },
    success: "on_question_reply"
});

3. Submit Answer Action

Action: submitAnswer. Sends user's answer back for verification.

Bots.Business (Answer Verification) 
// Assuming variables n1, n2, op are saved in User properties
HTTP.post({
    url: "https://kumar-lac.vercel.app/api/bot",
    headers: { "Content-Type": "application/json" },
    body: {
        "userId": "",
        "action": "submitAnswer",
        "num1": User.getProperty("temp_n1"),
        "num2": User.getProperty("temp_n2"),
        "operator": User.getProperty("temp_op"),
        "answer": message // User's input
    },
    success: "on_answer_reply"
});
